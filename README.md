# 🧮 JavaScript Calculator

A simple web-based calculator built with **HTML, CSS, and JavaScript**.  
It allows users to perform basic arithmetic and mathematical operations interactively.

---

## 🚀 Features
- Addition (Sum)
- Subtraction (Difference)
- Multiplication (Product)
- Division (Quotient) with zero-check
- Remainder (Modulo)
- Power (Exponentiation)
- Square Root (for both numbers)
- Square (for both numbers)

# 🧮 JavaScript Calculator

A simple web-based calculator built with **HTML, CSS, and JavaScript**.  
It allows users to perform basic arithmetic and mathematical operations interactively.

---

## 🚀 Features
- Addition (Sum)
- Subtraction (Difference)
- Multiplication (Product)
- Division (Quotient) with zero-check
- Remainder (Modulo)
- Power (Exponentiation)
- Square Root (for both numbers)
- Square (for both numbers)
  
---

## ⚙️ How It Works
1. Enter two numbers in the input fields.
2. Select an operation from the dropdown menu.
3. Click the **Calculate** button.
4. The result will be displayed below.

---

## 🖥️ Example Usage
- Input: `num1 = 10`, `num2 = 5`, Operation = `sum`  
- Output: `Sum: 15`

- Input: `num1 = 9`, `num2 = 0`, Operation = `quotient`  
- Output: `Cannot divide by zero`

---

## 📌 Setup Instructions
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start calculating!
